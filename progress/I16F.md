## 特殊点

- 权威边界：单张现价、市值和未实现盈亏由 SQLite 读取 `market_quotes` 时以整数计算；浏览器只格式化服务端 DTO，不能使用数量、成本或可用量重算。
- 锁定与 `all`：页面不提交或解锁库存；`all` 仅传给服务端预览，确认只回传服务器已解析的确切数量，订单与比赛锁定量无法出售。
- 幂等与重复点击：同一预览的网络重试复用幂等键；同步确认锁同时阻断 React 重新渲染前的快速双击，防止第二个 HTTP 请求。
- 兼容性：无需数据库迁移；新增 DTO 字段由既有库存读取路由与 NPC 成交响应一并返回。报价缺失时估值字段保持明确不可用，旧持仓估值仍可作为服务器最后成功值显示。
