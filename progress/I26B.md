## 特殊点与风险

- 权威边界：API + SQLite 是成就进度、解锁、奖励和审计的唯一写入者；浏览器仅查询，规则全部位于 `@mtg-market/rules` 的纯函数。
- 幂等与审计：任务以 fact ID 唯一投递；解锁与奖励记录以 `(user_id, definition_id)` 唯一约束收敛。奖励、账本/库存、风控计数与审计都处于同一短事务，任一失败会回滚。
- 风控取舍：奖励超出每日次数或重复参赛上限时，成就仍不可变地解锁，但奖励记录为 `blocked` 并保留审计；不得直接修改计数、奖励或余额补发。
- 验证：`pnpm --filter @mtg-market/rules test`、`pnpm --filter @mtg-market/contracts test`、`pnpm --filter @mtg-market/database test`、`pnpm --filter @mtg-market/api test` 与 `pnpm check` 通过。
