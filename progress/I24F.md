## 特殊点与风险

- 权威边界：浏览器只提交卡表并显示 API 结果；Commander 合法性、禁牌版本、库存冲突、评分与锁定均不在浏览器计算。
- 幂等与审计：保存调用既有 `POST/PUT /v1/decks` 并按同一内容重试复用 UUID 幂等键；草稿保存不改变余额、库存或任何 hold。
- 数据兼容性：迁移 `0027_card_display_fields` 只增加非经济目录展示字段；部署后需重启 API 应用迁移，并由管理员投递一次受控 Scryfall 目录同步补全历史数据。五种虚拟基本地继续仅为服务端既有 DTO 枚举。
- 已知限制：报名评分仅会在后续 I25B 报名流程生成，草稿页面明确显示未生成而不伪造可用性。
- 验证：`pnpm --filter @mtg-market/web check`、`pnpm --filter @mtg-market/api check`、`pnpm --filter @mtg-market/database test`、目录/库存 API 测试均通过；桌面及 390 × 844 窄屏各执行 `apps/web/tests/e2e/decks.spec.ts` 4 项并通过。
