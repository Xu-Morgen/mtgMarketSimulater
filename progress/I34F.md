## 特殊点与风险

- 权威边界：涨跌方向/幅度、指数走势、提醒命中与触发价、盘口累计量/中间价/价差、批量卖出汇总全部只展示 I34B 服务端 DTO；浏览器不计算涨跌、不重判命中、不累计盘口、不统计批量汇总。bp→百分比仅为展示格式化；SVG 迷你走势条只连接服务端采样点，不插值。
- 幂等与审计：Watchlist 写操作（添加/启停/删除/标记已读）与按筛选批量卖出在组件层按意图固定幂等键 + 同步双击锁只投递一次；成功后只失效服务器真相查询，结果横幅来自 mutation 返回值，刷新即消失不伪造成功。
- 公告与叙事边界：公告区只展示标题/范围/生效区间并可按系列跳转目录，不暴露 `factor_bps` 等内部系数；叙事横幅只展示服务端 `bias` reason 文案（按文案去重），无 bias 原因时不显示。
- 批量卖出取舍：候选只取当前页有可用量的 SKU（跨页仅当前页，筛选可换页）；锁定/无价/额度用尽的 SKU 由服务端跳过并汇总，页面不推断。
- 回归修复：两个 API 测试夹具的「当日额度已用尽」成交日期改为与运行当天一致，属于既有 I33B/I34B 测试的日期敏感修正，不改断言、不改变业务代码。
- 待决：无。e2e（`apps/web/tests/e2e/market-heat-watchlist-i34f.spec.ts` 桌面 + 窄屏）与人工验收由用户按 AGENTS.md 第 7 节在本机手动执行并补登。
- 验证：`pnpm check`（lint + 全 workspace tsc）通过；contracts 13、rules 85、database 4、api 245（1 跳过）、web 5 全过；`next build` 通过（`/watchlist` 路由生成）。
