## 特殊点与风险

- 权威边界：图鉴完成度/未收集卡位、开包新卡标记、系列进度快照、批量开包汇总、重复卡清仓汇总与限时窗口状态全部只展示服务端 DTO；浏览器不统计、不估值、不推导新卡/盈亏或里程碑解锁。bp→百分比仅为展示格式化。
- 幂等与审计：批量开包与重复卡卖出在组件层按意图固定幂等键，网络重试只投递一次；成功后只失效服务器真相查询（archive/ledger/inventory/pack-openings/collection album/achievements），结果横幅来自 mutation 返回值，刷新即消失不伪造成功。
- 限时包取舍：折扣价格只展示服务端 `preview.cost`；`scheduled`/`ended` 窗口与下架同语义禁用购买并展示固定拒绝原因；剩余时间倒计时为浏览器本地格式化，不参与任何资格判定。
- 动画边界：开包动画状态仍只存于可丢弃的 Zustand 动画 store；批量开包结果直接展示服务端汇总，无动画。卡图仅经带会话的本地 API 读取，绝不访问外部图片 URL。
- 待决：无。Playwright 与人工验收由用户按 AGENTS.md 第 7 节在本机手动复跑并补登到手动测试记录。
- 验证：`pnpm check` 通过；`pnpm lint` 通过；web vitest 5 例通过；全仓 `pnpm -r test` 结果见会话（contracts/rules/database/api/web 全量）。
