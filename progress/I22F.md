## 特殊点与风险

- 权威边界：浏览器只读取本地 API 的服务端订单、成交、余额和库存投影；不计算或持久化经济真相。SQLite 重开、任务重复领取、账本、审计和事实事件对账由 I22B 后端集成回归负责。
- 幂等与恢复：回归确认刷新和新浏览器上下文不会重放履约/撤单 mutation；到期回收后仅恢复 `cancelled` 终态。
