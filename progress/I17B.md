## 特殊点

- 权威边界：历史查询只读只追加的 `price_snapshot_entries`/`market_quotes`，不为历史另建存储表，避免与 append-only 设计漂移；回填不写 `price_sync_state`/`price_sync_schedule_state`、不为历史日投递 `market.reprice`；调度器只投递任务，不直接写经济真相。
- 契约与迁移：迁移 `0018` 用 `NOT NULL DEFAULT 'daily'` 保证旧行兼容；`PriceSyncRunDto.runKind` 区分 daily/backfill；`PublicPriceStatusDto.disclaimer` 由服务端固定文案，浏览器只展示。回填监督 run 以 `mapping_uri='supervisor'`、子 run 以 `mapping_uri='sub-run'` 标记，区别于日常同步的 `mapping_uri` 实际下载地址。
- 幂等与审计：回填以 `(sku_id, 自然日)` 去重 + `(type, unique_key)` 任务唯一键 + 条件 UPDATE 收敛；日切以 `last_scheduled_date` + `prices.sync:daily:<date>` 收敛；失败留 failed 监督运行，不替换旧数据。POST backfill 写 `price_backfill.requested` 审计；成功完成写结构化日志。
- 事务：回填下载/校验/写入在一笔短事务内完成；事务中断不留半批次子 run 或快照。
- 数据源说明：MTGJSON/Cardmarket 参考价 + 虚拟货币 GAME_CREDIT + 非实时/非真实资产，服务端固定文案。
- 延后项：`daily.rollover` 的发钱/赛事刷新（AT-10B）按验收延后至 I23B/I25B，本轮只接 `prices.sync` 调度；前端双曲线/ECharts 图表、时间范围切换、空数据降级表格与人工核对为 I17F。
- 验证：已通过 `pnpm --filter @mtg-market/api test`（74 测试）、`pnpm --filter @mtg-market/database test`（4）、`pnpm --filter @mtg-market/contracts test`（4）与全 workspace `pnpm check`（tsc --noEmit）。
