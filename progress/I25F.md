## 特殊点与风险

- 权威边界：浏览器仅展示 API 返回的赛事、赛果、奖励、重放、库存锁定和同桌权限结果；不计算积分、排名、奖励、随机池或解锁。
- 幂等与安全：所有比赛写操作复用同一用户意图的 `Idempotency-Key`；历史和玩家赛事列表仅返回当前用户已报名或创建的记录。NPC 重放沿用参赛者可读边界；非 NPC seed/完整 replay 仍只对管理员开放。
- 数据兼容性：新增端点为只读投影，没有迁移、规则版本或存档数据变更。
- 已知限制：真实业务日全链路浏览器演练仍依赖 I25B 受控数据库夹具；本迭代以 API 夹具覆盖页面分支，未把赛事或经济真相复制到前端。
- 验证：`pnpm check`、`pnpm --filter @mtg-market/api test -- tournament-routes.test.ts`、`apps/web/tests/e2e/tournaments.spec.ts` 在 Chromium 桌面（5/5）和窄屏（5/5）均通过。
