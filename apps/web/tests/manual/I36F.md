# I36F：新手引导与首次体验页面人工验收

日期：2026-08-05（Tour 跨页引导与「创建存档」第一步升级，同日更新）

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I36F 固定本地 API 夹具；新手引导投影（七步首次目标链：创建存档/领取工作资金/开出第一包/看懂价格/完成首笔交易/收藏见涨/首次报名）、浏览意图/跳过/领取命令与玩家首页（常驻引导入口、服务端待办「继续新手引导」）均由标准响应包络返回；价格历史页只读数据沿用 I17F 夹具。

## 操作与结果

1. 打开 `/onboarding`：核对玩家导航「大厅」组「新手引导」入口；页面展示进度摘要（「引导进度 x%」aria 说明、已完成 x/7 步、下一步高亮、规则版本与服务端更新时间）与七步目标链清单，第一步为「创建存档」。
2. 点击「开始引导」：出现 antd Tour 气泡，第一步「创建存档」高亮玩家首页「创建游戏存档」按钮（气泡指向按钮、蒙层不拦截）；真实点击按钮创建存档后，Tour 自动前进到「领取工作资金」并高亮首页领取按钮；领取后再前进到「开出第一包」。
3. 跨页跟进：「开出第一包」点击「去完成 →」跳转补充包商店，气泡高亮「购买并开包」按钮；「看懂价格」跳转价格历史页并高亮双曲线区，页面展示「已向服务器记录本次价格历史浏览」（浏览意图只投递一次）；「完成首笔交易」在市场页高亮「向 NPC 买入」按钮；「收藏见涨」「首次报名」分别高亮收藏图鉴与今日比赛页。
4. 跳过与重进：Tour 内「跳过此步」为幂等命令（二次确认后只投递一次），跳过视为已完成、自动前进到下一步，已跳过步骤显示「（已完成）」且不再提供跳过入口；关闭 Tour 后进度仍以服务端投影为准，刷新不伪造进度；引导页可随时「开始引导/引导我完成」重进任一步骤。
5. 完成奖励领取：全部七步完成后奖励状态为可领取；点击「领取 500 游戏币」→ 二次确认 → 确认后只投递一次；成功横幅展示服务端入账金额与入账后可用余额（如「已领取引导完成奖励 500 游戏币，当前可用余额 13,000 游戏币（由服务器入账）」），状态刷新为已领取、领取按钮消失。
6. 首页联动：未完成玩家首页显示常驻「新手引导」区块（进行中徽标「引导进行中 x/7」、下一步文案、「继续引导」按钮直接启动 Tour）；服务端待办出现「继续新手引导」并跳转 `/onboarding`；引导完成后待办随服务端聚合消失。
7. 未创建存档的新玩家：登录后首页显示「尚未创建游戏存档」与创建存档按钮，同时展示常驻「新手引导」区块（徽标「引导进行中 0/7」、下一步「创建存档」），「继续引导」直接启动 Tour 高亮「创建游戏存档」按钮（引导第一步即创建存档）。
8. 在 390 × 844 窄屏重复上述引导页、Tour 气泡、领取弹窗、首页入口（含未存档玩家首页）核对，确认无横向阻断、气泡与按钮可读可操作。

## 实际结果

待用户手动执行并补登（本机按 AGENTS.md 第 7 节不自动运行 e2e；`apps/web/tests/e2e/onboarding-i36f.spec.ts` 桌面与窄屏两项目共 5 项覆盖上述路径）。页面仅呈现 I36B `onboarding/v2` 的服务端事实：步骤完成、跳过、奖励状态均由服务端基于已结算事实/访问事件判定，Tour 只标记按钮与提交意图（浏览/跳过/领取）并复用幂等键，不判定完成、不结算任何经济真相。
