# I36F：新手引导与首次体验页面人工验收

日期：2026-08-05

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I36F 固定本地 API 夹具；新手引导投影（六步首次目标链、完成度、下一步、完成奖励状态）、浏览意图/跳过/领取命令与玩家首页（常驻引导入口、服务端待办「继续新手引导」）均由标准响应包络返回；价格历史页只读数据沿用 I17F 夹具。

## 操作与结果

1. 打开 `/onboarding`：核对玩家导航「大厅」组新增「新手引导」入口；页面展示进度摘要（「引导进度 x%」aria 说明、已完成 x/6 步、下一步高亮、规则版本与服务端更新时间）与六步目标链卡片（领取工作资金→开出第一包→看懂价格→完成首笔交易→收藏见涨→首次报名）；每张卡片展示目标说明、跳转按钮、可跳过标志，卡片内直接提供对应目标功能入口（/dashboard、/packs、/market/history、/market、/collection/album、/tournaments）。
2. 首次目标链串联：从「看懂价格」卡片点击「去完成」进入价格历史页，页面展示「已向服务器记录本次价格历史浏览」；服务端据此完成 view_event 步骤，返回引导页后进度刷新为「已完成 1/6」，刷新不伪造进度。
3. 跳过与重进：对「领取工作资金」点击「跳过此步骤」→ 二次确认弹窗（说明跳过视为已完成且不可恢复、重复点击只提交一次）→ 确认后只投递一次；刷新后该步骤显示「已跳过」徽标、下一步前移为「开出第一包」，已跳过步骤不再提供跳过入口；引导入口常驻玩家首页，未完成玩家显示「引导进行中 x/6」徽标与「继续引导」按钮。
4. 完成奖励领取：全部步骤完成后奖励状态为可领取；点击「领取 500 游戏币」→ 二次确认 → 确认后只投递一次；成功横幅展示服务端入账金额与入账后可用余额（如「已领取引导完成奖励 500 游戏币，当前可用余额 13,000 游戏币（由服务器入账）」），状态刷新为已领取、领取按钮消失；未完成全部步骤时只展示「完成全部引导步骤后，由服务器发放一次性奖励」，不显示领取入口。
5. 首页联动：未完成玩家首页显示常驻「新手引导」区块（进行中徽标、下一步文案、继续引导入口）；服务端待办出现「继续新手引导」并跳转 `/onboarding`；引导完成后待办随服务端聚合消失；引导与任务中心进度同源一致（同一已结算开包事实同时反映为引导「开出第一包」完成与任务中心「每日开包」进度）。
5A. 未创建存档的新玩家：登录后首页显示「尚未创建游戏存档」与创建存档按钮，同时展示常驻「新手引导」区块（徽标「引导进行中 0/6」、下一步「领取工作资金」、继续引导入口），可点击进入 `/onboarding` 查看首次目标链（引导只读查询对未存档玩家开放，领取完成奖励时服务端才要求存档）。
6. 在 390 × 844 窄屏重复上述引导页、跳过/领取弹窗、首页入口（含未存档玩家首页）核对，确认无横向阻断、按钮与徽章可读可操作。

## 实际结果

待用户手动执行并补登（本机按 AGENTS.md 第 7 节不自动运行 e2e；`apps/web/tests/e2e/onboarding-i36f.spec.ts` 桌面与窄屏两项目共 4 项覆盖上述路径）。页面仅呈现 I36B 的服务端事实：步骤完成、跳过、奖励状态均由服务端基于已结算事实/访问事件判定，浏览器只提交意图（浏览/跳过/领取）并复用幂等键，不判定完成、不结算任何经济真相。
