## 非开发者执行步骤（I21F checklist / AT-11 风控浏览器部分）

1. 玩家登录后进入市场，对某 SKU 挂买单。模拟服务端返回 `RULE_VIOLATION`「订单风控已拦截：下单冷却中」：应显示稳定、可行动的风控拒绝提示（如「风控拒绝：下单冷却尚未结束。请稍后重新获取服务端预览；不要反复提交同一请求。」），且提供「重新预览」入口；不应把同一请求反复提交。
2. 冷却结束后重新预览并合法挂单：应成功创建委托；合法交易与高频撤单不应被前端错误阻断。
3. 管理员登录后进入「异常订单」（`/admin/orders/risk`）：应列出服务端已持久化的风险决策（时间、结果、动作、原因、评分、规则版本），可按「已拦截 / 待复核」筛选。
4. 点击「查看详情」：详情对话框应显示决策 ID、结果、动作、风险评分、SKU、关联订单（创建前拦截显示「未生成订单」）、规则版本与记录时间，并给出「关联日志入口」说明（用决策 ID 在审计日志检索）。
5. 核对脱敏：页面不显示用户身份、账户余额、库存、资金/库存冻结、请求体或凭据；不出现「放行」「撤单」等资产写入按钮。
6. 用普通玩家账号直接输入 `/admin/orders/risk`：应显示无权访问页面；调用 `/v1/admin/orders/risk-decisions` 应返回 403。
