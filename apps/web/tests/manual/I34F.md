# I34F：市场行情与交易体验页面人工验收

日期：2026-08-05

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I34F 固定本地 API 夹具；行情屏（涨跌榜/活跃榜/迷你走势条）、公告、NPC 倾向叙事文案、Watchlist 条目/提醒/已读、盘口深度（累计量/中间价/价差）与按筛选批量卖出汇总均由标准响应包络返回。

## 操作与结果

1. 打开 `/market`：核对「市场」页导航新增「价格提醒」入口；行情屏展示日内/7 日涨跌幅榜（▲/▼ 方向徽标与服务端幅度）、当日最活跃交易榜（张数与金额）、游戏内指数迷你走势条（SVG 只读 7 日指数历史点）；报价表价格列显示 ▲/▼ 日内徽标，卡名、参考价与游戏内中间价均可点击跳转该 SKU 价格历史页（携带 `skuId`）。
2. 核对公告区：只展示系列周期/市场活动的标题、影响范围与生效区间；系列公告可跳转对应系列目录；页面不出现任何内部系数。
3. 核对市场叙事横幅：只展示服务端返回的 NPC 做市商倾向文案（不含系数），无 bias 原因时不显示横幅。
4. 打开 `/watchlist`：核对已触达提醒列表（未读数徽章、触发价与时间、跳转价格历史、标记已读）；搜索卡牌→选择→设置目标价类型/方向/目标价→二次确认添加，重复点击只投递一次；列表显示服务端保存的目标价/方向/启停状态与当前条数/上限；删除与启停均有二次确认且重复点击只投递一次。
5. 打开 `/orders`：核对盘口深度视图——买卖双栏逐档限价/剩余量/累计量/委托数，中间价与价差条由服务端给出（任一档缺失显示 —）；累计量不由浏览器累加。
6. 打开 `/inventory`：核对持仓卡名与现价可点击跳转价格历史；「批量卖出当前筛选」入口只提交当前筛选命中（有可用量）的 SKU，二次确认后展示服务端汇总（张数/收入/费用）与跳过明细，重复点击只投递一次。
7. 打开 `/catalog` 与 `/packs`：核对目录卡名与开包结果卡名/当前市场价可点击跳转价格历史。
8. 在 390 × 844 窄屏重复上述行情屏、公告、价格提醒、盘口与批量卖出核对，确认无横向阻断、按钮与徽章可读可操作。
