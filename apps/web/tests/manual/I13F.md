## I13F：来源、更新时间、过期/无价与权限隔离

- 操作步骤：管理员进入“价格同步”页面，核对最近成功快照和失败运行的版本、双 SHA-256、校验状态、映射/有价/无价/映射失败统计、任务和失败摘要；点击“主动刷新当日价格”并二次确认。构造稳定 `CHECKSUM_MISMATCH` 后，确认自动弹出的风险对话框，或取消而不投递；玩家进入目录查看价格状态；普通玩家直接访问 `/admin/price-sync` 并以其 token 请求 `/v1/admin/prices/sync`。
- 预期结果：管理员可见同步运行详情，失败后明确保留最近成功快照；刷新只投递一个带幂等键的本地 `prices.sync` 任务，等待/执行期间不能重复提交。checksum 覆写只会在稳定失败后出现，确认只投递一个 `{ allowChecksumMismatch: true }` 的本地任务，成功运行标记为管理员已确认绕过。玩家只见“MTGJSON / Cardmarket EUR 参考价”、更新时间/沿用旧快照状态和“无有效参考价，暂不可新增交易”；没有 Cardmarket 实时价或兜底价表述。普通玩家没有后台导航项，页面显示无权访问且 API 返回 403。
- 实际结果：通过。确认普通刷新后出现“当日价格同步任务已提交，可在此页持续追踪。”；确认 checksum 风险对话框后只向本地 admin API 投递一次覆写任务；管理页面未显示 Provider 下载地址或原始内容；玩家展示仅使用公开状态 DTO，不请求 `/v1/admin/*`；无价 SKU 保持不可新增交易。普通玩家的管理导航、直接页面和管理 API 均被隔离。
