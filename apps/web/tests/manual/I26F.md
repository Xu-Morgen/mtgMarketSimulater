# I26F：成就与收藏里程碑页面人工验收

日期：2026-07-30

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I26F 固定本地 API 夹具；成就定义、进度、解锁、奖励状态与来源均由标准响应包络返回。

## 操作与结果

1. 打开 `/achievements`，核对玩家导航、页面加载和服务端返回空定义时的明确空态；没有浏览器端解锁或发奖操作。
2. 以已解锁的赛事成就打开详情，核对进度、解锁时间、奖励、规则版本、fact/aggregate/correlation ID 与「查看关联赛事与历史」「查看账本流水」入口；`granted` 显示为「已由服务端发放（无需领取）」。
3. 刷新详情页，核对只重新读取同一服务端事实，不发出 POST/PUT/PATCH/DELETE，也不出现第二份奖励或成功提示。
4. 以收藏来源且 `blocked` 的成就打开详情，核对「已解锁，但奖励被服务端风控拦截」和「查看收藏与库存」入口；页面不提供补发或绕过风控按钮。
5. 在 390 × 844 下重复列表、详情和来源入口核对，确认状态标签、长来源 ID 和链接可阅读、可操作，无横向阻断。

## 实际结果

通过。上述路径已在 Chromium 桌面和窄屏的固定服务端夹具下核对；`apps/web/tests/e2e/achievements.spec.ts` 两个项目共 6 项通过。页面仅呈现 I26B 的只读事实，奖励发放和风控结果均不由浏览器推导或修改。
