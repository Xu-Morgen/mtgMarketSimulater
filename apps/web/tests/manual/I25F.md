# I25F：每日比赛、报名与结果页面人工验收

日期：2026-07-30

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I25F 固定服务端夹具；所有余额、库存、卡组、报名、赛果、奖励与权限响应均由 API 包络返回。

## 操作与结果

1. 打开 `/tournaments`，核对今日无赛事空态、创建玩家赛事入口、历史空态和导航入口。
2. 打开 NPC 瑞士轮的报名确认，选择已保存卡组并快速重复确认；核对请求仅携带 `deckId`、同一意图只发送一次，服务端返回「卡组已被比赛锁定」时页面保持失败状态，不显示报名成功或解锁结果。
3. 以已报名且截止结算中的 NPC 赛事刷新页面，核对服务端排名、胜平负、奖励、随机补充包凭证、公开 NPC seed/轮次重放和历史结果；页面不计算评分、积分、排名或奖励。
4. 打开现实桌赛事，核对只显示玩家填写的卡组名称、同桌报名与轮次、4/1/0/1/0 规则；提交非同桌赛果后显示服务端 `AUTHORIZATION_DENIED`，不在本地变更积分或确认状态。
5. 在 390 × 844 下重复以上入口与结果查看，确认卡片、确认弹窗、奖励领取按钮和轮次操作可访问，没有阻断性横向布局。

## 实际结果

通过。上述交互已在 Chromium 桌面与窄屏各运行一次：`apps/web/tests/e2e/tournaments.spec.ts` 两个项目共 10 项通过。比赛页面只呈现服务端状态；结算、奖励、库存 hold 释放、全桌确认权限与随机重放均未由浏览器推导。
