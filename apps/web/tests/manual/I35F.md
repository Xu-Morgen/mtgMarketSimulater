# I35F：留存钩子与成长线页面人工验收

日期：2026-08-05

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I35F 固定本地 API 夹具；任务中心（今日/本周实例、进度、可领取状态、服务端周期键）、等级档案（等级/称号/经验/能力/峰值净资产）与首页待办「领取任务中心奖励」均由标准响应包络返回。

## 操作与结果

1. 打开 `/tasks`：核对玩家导航「赛事与成长」组新增「任务中心」入口；页面展示等级卡片（称号、Lv 徽章、经验条与「经验进度」aria 说明、NPC 每日交易额度倍数、批量开包上限、历史峰值净资产与服务端更新时间），全部取服务端档案，不在浏览器推算经验。
2. 核对今日/本周任务：每条任务展示标题、说明、指标类型、服务端周期键（日 YYYY-MM-DD / 周 YYYY 年第 N 周）、只读进度条（aria 说明「任务进度 x%」）、「当前 / 目标」数值与「进行中 / 可领取 / 已领取」状态徽标；达标实例显示「领取 <金额> 游戏币」按钮，已领取实例显示禁用的「奖励已领取」。
3. 领取：点击「领取」→ 二次确认弹窗（说明奖励金额与重复点击只提交一次）→ 确认后只投递一次；成功横幅展示服务端入账金额与入账后可用余额（如「已领取奖励 80 游戏币，当前可用余额 12,080 游戏币（由服务器入账）」），任务状态刷新为「已领取」；网络重试复用同一幂等键。
4. 失败与空态：任务中心加载失败显示错误重试；无任何任务定义显示空态；领取失败显示服务端错误文案并可重试；无可领取奖励时横幅显示「当前没有可领取的任务奖励」。
5. 打开 `/dashboard`：核对「等级与声望」区块复用同一等级卡片；「今日循环」入口新增「查看任务中心」；服务端待办在存在可领取任务奖励时显示「领取任务中心奖励」并跳转 `/tasks`，领取后随下一次服务端聚合消失。
6. 在 390 × 844 窄屏重复上述任务中心、领取弹窗与首页核对，确认无横向阻断、按钮与徽章可读可操作。
