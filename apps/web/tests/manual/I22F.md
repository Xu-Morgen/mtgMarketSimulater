1. 使用两个隔离浏览器窗口分别登录买方与卖方，进入“我的委托”。买方挂 3 张、限价 200 的买单；卖方挂 3 张、限价 200 的卖单，等待服务端撮合 2 张。
2. 两端刷新页面并截图：买方应显示待履约资金 408 游戏币（2 × 200 + 8 order_fee），卖方应显示待履约库存 2 张和待履约保证金 40 游戏币；两端剩余委托均为 1 张。
3. 卖方撤销剩余 1 张卖单；买方在二次确认框确认履约 `trade-i22f-partial`。分别截图成功横幅和订单/成交表。
4. 两端分别刷新。核对成交只显示“已完成”、卖方委托显示“已撤单”、冻结额为 0；不应再出现履约操作、重复成功提示或额外资产变化。
5. 重启本地服务后，使用新的浏览器窗口重新登录两端并再次刷新。对一个由服务端取消履约或 `order.expire` 到期回收的成交，核对两端均显示“已取消”、冻结额为 0、无待履约摘要且没有履约/取消按钮；截图订单、成交和余额状态卡。
6. 在服务端 I22B 对账记录中，以订单 ID、成交 ID 和请求 ID 核对可用/冻结资金、可用/锁定库存、保证金 hold、账本、审计及事实事件；不得手工修改数据库或绕过订单命令。
