# I33F：收藏图鉴与开包体验页面人工验收

日期：2026-08-04

## 环境

- 浏览器：Chromium 桌面与 390 × 844 窄屏。
- 数据：I33F 固定本地 API 夹具；图鉴聚合、开包 DTO（新卡/重复标记、系列进度、总成本/总价值）、批量开包汇总、重复卡批量卖出汇总、限时 offer 状态与里程碑成就进度均由标准响应包络返回。

## 操作与结果

1. 打开 `/collection/album`，核对玩家导航「收藏图鉴」入口、页面加载与空态；按系列分组展示服务端完成度百分比、已收集/全部 SKU 数、未收集卡位灰影占位（稀有度描边仅视觉暗示）；「全部系列/仅持有」切换写入 URL 且只重读服务端聚合。
2. 核对收藏里程碑联动区：只读展示系列收集率成就的进度/解锁状态与奖励，跳转成就详情；不提供浏览器解锁或发奖操作。
3. 在 `/packs` 完成单包开包：核对每张卡展示本地卡图（缺图文字降级）、稀有度辉光、新卡/重复徽标、所在系列进度，以及本包成本与服务端估值对比（盈亏红绿徽章）；跳过动画后结果仍为服务端 DTO。
4. 批量开包：数量选择（10/50/100）+ 二次确认，提交期间按钮禁用；重复点击只投递一次；汇总卡片展示服务端包数/总成本/总估值/新 SKU 数与稀有度分布；「逐包下钻」只读已结算逐包记录（首包新卡、后续包重复）。
5. 重复卡一键清仓：开包结果页与库存页均有入口，二次确认只提交一次；结果横幅展示服务端张数/收入/费用与跳过明细；刷新后横幅消失（不伪造成功）。
6. 限时包：在 `/packs` 与 `/packs/[id]` 核对折扣标签（如 -20%）、剩余时间文案与卡池说明；`ended` 状态包展示服务端拒绝原因且购买/批量开包按钮禁用。
7. 在 390 × 844 窄屏重复上述图鉴、批量开包汇总/下钻与清仓横幅核对，确认无横向阻断、按钮与徽章可读可操作。

## 实际结果

通过。上述路径已在 Chromium 桌面和窄屏的固定服务端夹具下核对；`apps/web/tests/e2e/collection-album-i33f.spec.ts` 两个项目共 5 项通过。页面仅呈现 I33B 的服务端事实，新卡/盈亏/完成度/汇总均不由浏览器推导，批量开包与清仓写操作只提交意图并复用幂等键。
