## FE-MARKET / FE-CATALOG：价格历史双曲线、范围切换与旧价降级

- 前置数据：服务端 `price_snapshot_entries`/`market_quotes` 已按自然日采样；`/v1/market/index/history`、`/v1/market/quotes/{skuId}/history` 与 `/v1/prices/status` 返回固定夹具。
- 操作步骤：进入“市场 → 价格历史与市场曲线”（`/market/history`）。核对市场指数双曲线（金色 Cardmarket EUR 参考指数均值、蓝色游戏内市场指数均值）、来源说明、更新时间/过期状态与固定 disclaimer；依次点击“近 7 天 / 近 30 天 / 全部”切换时间范围；用名称/系列/稀有度/工艺搜索候选 SKU，选中一张卡牌查看其单卡双曲线与降级表格。分别模拟单卡空历史、`freshness=stale` 与指数历史 500 错误；在桌面与窄屏复测。
- 预期结果：页面只读取服务端按日采样的历史，不在浏览器插值、重算指数或汇率；某日参考价/游戏内价缺失时该段断线（`connectNulls=false`），不掩盖空态。默认 30d 不强制写入 URL，切换 7d/全部才把 `range` 写入 URL 并以新 `range` 重新查询；选中 SKU 写入 `skuId`。空历史显示“该 SKU 暂无历史快照”，绝不伪造价格；`stale` 时仍展示旧快照指数、过期状态与“沿用最近成功快照；这不是实时 Cardmarket 价格。”；查询失败显示错误重试而非空白或伪实时价格。窄屏下图表高度与降级表格不阻断阅读。
- 实际结果：通过。默认 30d 首次以 `range=30d` 请求且图表渲染；点击“近 7 天/全部”后 URL 变为 `range=7d`/`range=all` 并重新查询。选中 SKU 后单卡双曲线渲染，图例区分金色“Cardmarket EUR 参考价”与蓝色“游戏内中间价”，降级表格显示 `2026-07-26` 当日无参考快照并断线。空历史显示空态标题且图表不渲染；`stale` 时指数图表仍渲染并显示旧价与过期状态；500 错误显示“市场指数历史读取失败”与重试按钮，无图表区域。窄屏（390 × 844）下图表、范围切换与表格均可见可用。
- 证据：`apps/web/tests/e2e/price-history.spec.ts` 覆盖范围切换与 URL 同步、单卡双曲线/降级表格/空历史、`stale` 旧价降级、查询失败重试、窄屏；桌面与窄屏均执行。请求断言验证 `/v1/market/index/history*` 与 `/v1/market/quotes/*/history*` 携带服务端 `range` 参数，不向浏览器之外的 Provider 发起请求。
