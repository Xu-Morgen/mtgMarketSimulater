## 二、新增六节（插在 I32AI 之后、原 I33B 之前），含全部功能要点

### I33B：收藏图鉴与开包体验服务端
- [ ] 收藏聚合只读 API `GET /v1/collection/album`：按系列分组图鉴、每系列已收集/全部 SKU 数与完成度、未收集卡位列表（卡名/系列/编号/稀有度），来自目录+库存快照，不写经济表。
- [ ] 开包结果 DTO 扩展：每张卡返回 `isNewToCollection`（本次结算前是否已持有）、`collectionProgressAfter`（该系列完成度快照）；`PackOpeningDto` 返回本包总成本与总价值（按结算时报价快照）；浏览器不得自行比对库存推导。
- [ ] 批量开包（C7）：`POST /v1/packs/bulk` 支持 10/50/100 包，单事务批量结算，汇总 DTO（各稀有度计数、总成本、总价值、新增 SKU 数），幂等与费用约束复用 pack/v1。
- [ ] 重复卡批量处理（C8）：`POST /v1/inventory/duplicates/sell` 按筛选/全持有批量向 NPC 卖出，受每日额度与报价快照约束，账本+库存流水同事务，返回张数/收入/费用汇总；复用既有 NPC 卖出规则。
- [ ] 系列收集率里程碑成就（扩展 I26B 成就系统）：定义"收集某系列 80%/100%"成就与自动解锁发放，复用不可变流水与幂等消费者防重复发奖。
- [ ] 特殊补充包（C6）：后台可配置限时/折扣/主题包（启用时段、折扣、可选限定卡池或概率覆盖）；过期/未启用包由服务端拒绝购买。
- [ ] 测试：图鉴聚合分页/权限、开包字段断言、批量开包金额一致与幂等、批量卖出并发/额度/回滚、里程碑防刷、限时包过期不可购买。

### I33F：收藏图鉴与开包体验页面
- [ ] 收藏册图鉴页：按系列分组网格，未收集灰影占位（可切换仅持有/全部），系列完成度百分比与稀有度描边高亮；只展示服务端聚合。
- [ ] 开包结果页升级：每张卡展示牌面卡图、稀有度辉光、"新卡/重复"徽标、本包成本与价值对比（盈亏红绿）；动画只展示已结算结果。
- [ ] 批量开包 UI：数量选择（10/50/100）+ 二次确认 + 汇总结果卡片（可下钻逐包），提交期间禁用、重试复用幂等键。
- [ ] 重复卡一键清仓：开包结果页与库存页"批量卖出重复/按筛选卖出"入口，结果横幅展示收入与费用。
- [ ] 限时/特殊包展示：剩余时间、折扣标签、卡池说明；过期包显示服务端禁用原因。
- [ ] 里程碑成就展示：与图鉴联动，进度与奖励只读服务端。
- [ ] Playwright：图鉴空态/分组/未收集占位、新卡与重复标记、批量开包重复点击只投递一次、批量卖出幂等、限时包过期禁用、390px 窄屏。

### I34B：市场行情与交易体验服务端
- [ ] 行情统计只读 API `GET /v1/market/heat`：日内/7 日涨跌幅榜与最活跃交易榜（按服务端报价快照与成交事实聚合），浏览器不计算涨跌。
- [ ] 批量交易（D4）：`POST /v1/npc-trades/sell/batch` 按筛选条件批量卖出，逐 SKU 走既有 NPC 规则与额度，单事务汇总落账本与库存流水。
- [ ] 价格提醒/Watchlist（E12）：`GET/POST/DELETE /v1/watchlist`（SKU、目标价、方向、启停），每玩家每 SKU 去重与数量上限；触达检测任务（复用任务框架，幂等、至多一次通知）生成站内通知与只读查询。
- [ ] 订单簿盘口聚合：扩展 `GET /v1/orders/book/{skuId}` 为按价格档聚合的买盘/卖盘深度（价格档、累计数量）。
- [ ] 系列周期与活动公告只读 API：已生效系列周期、市场活动以公告列表暴露（标题、影响范围、生效区间），不含内部系数。
- [ ] NPC 做市商倾向行为（E8/E14 增强）：市场系数增加可配置"NPC 倾向"因素并写入报价 reason（如"NPC 本周扫货 X 系列"），系数仍受既有上下限约束。
- [ ] 测试：涨跌幅聚合、Watchlist 增删/额度/重复、提醒任务幂等并发、公告权限与过期、盘口聚合、NPC 倾向边界、批量卖出回滚。

### I34F：市场行情与交易体验页面
- [ ] 市场页行情屏：涨跌幅榜（涨/跌前 10）、游戏内指数迷你走势条（复用 index history）、价格列显示服务端计算的涨跌方向幅度（▲/▼）。

- [ ] 盘口深度视图：订单簿页经典双栏盘口（买/卖价格档+累计量+中间价+价差），只读服务端聚合。
- [ ] Watchlist 页与提醒通知：增删改目标价提醒、触达通知列表、未读与跳转。
- [ ] 系列周期与活动公告区：市场页展示服务端公告（新系列倒计时、停印、活动影响），可跳转对应系列。
