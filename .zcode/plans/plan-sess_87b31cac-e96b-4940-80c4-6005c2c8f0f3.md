## 方案:市场页新增按价格排序

### 目标
市场页当前**完全没有排序功能**(无下拉框、后端无 sort 参数)。新增按"游戏内中间价"和"EUR 参考价"排序,每个价格支持降序/升序。无报价(quote=null)的卡**始终垫后**(沿用库存市值排序已验证的 `IS NULL ASC` 模式)。

### 核心边界(符合 AGENTS.md)
- 排序在 **SQLite 查询层**完成(整数最小货币单位,欧分/游戏币),不下放浏览器。NPC 报价不做排序(按你选择)。
- 排序键 + direction 均经 zod 白名单 + 固定模板,**无注入风险**。
- 保留现有的 name/code/number/finish 默认排序作为默认值。

### 改动文件(端到端 6 处)

**后端(3 处):**

**1. `apps/api/src/modules/market/api/market-routes.ts:8-16`** — zod schema 加 sort/direction
- `sort: z.enum(["name", "marketPrice", "referencePrice"]).default("name")`(默认 name,对应当前硬编码的按名称排序,保持向后兼容)。
- `direction: z.enum(["asc", "desc"]).default("asc")`(当前默认按名称升序,故 asc)。
- schema 仍是 `.strict()`,这两个新字段会被识别。

**2. `apps/api/src/modules/market/application/market-service.ts`** — 类型 + SQL 排序
- `:16-24` `MarketQuoteFilters` 加 `sort: "name" | "marketPrice" | "referencePrice"` 和 `direction: "asc" | "desc"`(非可选,有默认值,与 zod 一致)。
- `:171` 把硬编码 ORDER BY 改为白名单映射 + 拼接(参考库存 `sqlite-inventory-repository.ts:130-131` 模式):
  - `const direction = filters.direction.toUpperCase();`
  - 映射表:
    - `name` → `p.name COLLATE NOCASE ${direction}, s.code, p.collector_number, sku.finish`(保留现有默认排序的全部 tiebreaker)
    - `marketPrice` → `quote.market_price_amount IS NULL ASC, quote.market_price_amount ${direction}`(null 垫后)
    - `referencePrice` → `quote.reference_price_eur_cents IS NULL ASC, quote.reference_price_eur_cents ${direction}`(null 垫后)
  - 统一追加稳定 tiebreaker: `... ORDER BY ${order}, p.name COLLATE NOCASE ASC`(价格相同时按名称稳定排序,保证分页稳定;name 分支已有 tiebreaker 不重复加)。
  - **关键**:价格列经 LEFT JOIN,无 quote 时为 NULL,`IS NULL ASC` 让 null 在两种 direction 下都垫后(已用上轮库存测试验证过的模式)。

**3. 无需改 contracts** — `MarketQuoteListItemDto` 不变(排序是查询参数,不在响应 DTO)。

**前端(3 处):**

**4. `apps/web/api/market-api.ts:8-16`** — `MarketFilters` 加 `sort?: "name" | "marketPrice" | "referencePrice" | undefined; direction?: "asc" | "desc" | undefined;`

**5. `apps/web/features/market/market-page.tsx`** — URL 解析 + 排序下拉框
- `filtersFromSearch`(:26-34)加 `sort` 白名单解析(`"name"|"marketPrice"|"referencePrice"`,默认 `"name"`)、`direction`(默认 `"asc"`)。
- `toUrl`(:35-39)加默认值省略:`!(key === "sort" && value === "name")`、`!(key === "direction" && value === "asc")`。
- `apply()`(:86)带上 `sort: filters.sort, direction: filters.direction`(否则点"应用筛选"会丢排序,与库存页一致)。
- FilterBar(:93)在"交易状态"之后、"应用筛选"按钮之前插入排序 `<select aria-label="市场排序">`,即时跳转并 `cursor: undefined`(参考库存页 `:92`),option:
  - `name:asc` → 名称(升序)
  - `marketPrice:desc` → 游戏内中间价(降序)
  - `marketPrice:asc` → 游戏内中间价(升序)
  - `referencePrice:desc` → EUR 参考价(降序)
  - `referencePrice:asc` → EUR 参考价(升序)

### 测试(AGENTS.md 第 7 条)
